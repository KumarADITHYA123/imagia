# Iimagia — AI Image Generator

A text-to-image platform built with Next.js that lets users generate images from text prompts using multiple AI models including SDXL, Flux Schnell, Stable Diffusion, and Dreamshaper.

**[Live Demo →](https://iimagia.netlify.app/)**

## Features

- **Multi-model support** — Generate images using Flux Schnell, SDXL, Stable Diffusion, and Dreamshaper
- **Dynamic model switching** — Select different models from the UI for varied generation styles
- **Client-side rate limiting** — Prevents excessive generation requests
- **Latency tracking** — Displays time taken for each image generation
- **Image gallery** — View all generated images in a scrollable gallery
- **Dark mode UI** — Responsive design with one-click image download
- **Deployed on Netlify** — Production-ready

## Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **UI Components:** shadcn/ui
- **Deployment:** Netlify

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.
